## Python Classes and Objects

- **Class Definition**: A class is a blueprint for creating objects. It defines the behavior an object will have through its attributes and methods. Here is a basic example of a class definition in Python:

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f'{self.name.upper()} says woof woof!')
```

- **Class Naming Convention**: Class names in Python use the **PascalCase** convention, where each word starts with a capital letter, like `Dog`, `ShoppingCart`, or `UserSession`.

- **The `__init__()` Method**: `__init__()` is a special method that Python calls automatically every time a new object is created from the class. You use it to initialize the object's attributes with the values passed in when the object is created.

- **The `self` Parameter**: The first parameter of an instance method is a reference to the specific object the method is working with. When you call a method like `dog1.bark()`, Python automatically passes `dog1` as that first argument, so you don't pass it yourself. By convention, this parameter is named `self`, although any name would technically work. `self` lets a method access the object's own attributes and methods, such as `self.name`.

- **Creating Objects**: Objects are instances of a class. They are created by calling the class with the necessary arguments.

```python
dog1 = Dog('Jack', 3)
dog2 = Dog('Thatcher', 5)

dog1.bark()  # JACK says woof woof!
dog2.bark()  # THATCHER says woof woof!
```

- **Calling Methods on Objects**: You can call methods on objects to perform actions or retrieve information.

```python
object_name1.method_name()
object_name2.method_name()
```

- **Difference Between Class and Object**: A class is a reusable template, while an object is a specific instance of that class with actual data.

## Attributes

- **Instance Attributes**: Usually defined in `__init__()` using `self`, and unique to each object.
- **Class Attributes**: Defined directly inside the class and shared by all instances.

```python
class Dog:
    species = 'French Bulldog'  # Class attribute

    def __init__(self, name):
        self.name = name  # Instance attribute

print(Dog.species) # French Bulldog

jack = Dog('Jack')
print(jack.name)     # Jack
print(jack.species)  # French Bulldog
```

## Handling Attributes Dynamically

- **Why Handle Attributes Dynamically**: Sometimes you don't know an attribute's name until your program is running, for example when it comes from user input or a configuration file. In that case, you can't use the regular `object.attribute_name` syntax because the name isn't fixed in your code. Python provides built-in functions that work with attribute names stored as strings.

- **`getattr()`**: Reads an attribute by name. If the attribute doesn't exist, it raises an `AttributeError`, unless you pass an optional default value, which is returned instead.

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

person = Person('John Doe', 30)

print(getattr(person, 'name'))            # John Doe
print(getattr(person, 'city', 'Milano'))  # Milano

attr_name = input('Enter the attribute you want to see: ')
print(getattr(person, attr_name, 'Attribute not found'))
```

- **`setattr()`**: Creates a new attribute or updates an existing one by name.

```python
setattr(person, 'city', 'Rome')
print(person.city)  # Rome
```

- **`hasattr()`**: Checks whether an attribute exists and returns `True` or `False`. It's good practice to check before using or deleting an attribute.

```python
print(hasattr(person, 'age'))    # True
print(hasattr(person, 'email'))  # False
```

- **`delattr()`**: Removes an attribute by name.

```python
delattr(person, 'city')
print(hasattr(person, 'city'))  # False
```

- **Inspecting Attributes with `dir()` and `callable()`**: `dir()` returns a list of the attribute names available on an object, including dunder methods and regular methods. `callable()` returns `True` if the value passed to it can be called like a function or method. You can combine them to list only the data attributes of an object:

```python
for attr in dir(person):
    if not attr.startswith('__') and not callable(getattr(person, attr)):
        print(f'{attr}: {getattr(person, attr)}')

# Output:
# age: 30
# name: John Doe
```

## Methods

- **Methods**: Functions defined inside a class that operate on the object's attributes.

```python
class Car:
    def __init__(self, color, model):
        self.color = color
        self.model = model

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
print(my_car_1.describe())  # This car is a red Tesla Model S
```

- **Accessing Methods**: Call methods on objects using the dot notation. Here is an example of calling the `describe` method on two different car objects:

```python
class Car:
    def __init__(self, color, model):
        self.color = color  
        self.model = model  

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
my_car_2 = Car('green', 'Lamborghini Revuelto')

print(my_car_1.describe()) # Calling method using the dot notation

print(my_car_2.describe()) # Calling method using the dot notation
```

## Objects Working Together

- **Passing Objects as Arguments**: Methods can take other objects as arguments, and an object can pass itself using `self`.

- **Storing Objects in Attributes**: An attribute can hold another object, not only simple values like strings and numbers. This lets objects work together, like a user that owns an inbox.

- **Calling Methods Through an Attribute**: When an attribute holds an object, you can chain the dot notation to call that object's methods. For example, `receiver.inbox.receive_email(email)` first accesses the `inbox` attribute of `receiver`, which is an `Inbox` object, and then calls its `receive_email()` method.

Here's how the `User`, `Inbox`, and `Email` classes from the email simulator work together:

```python
class Email:
    def __init__(self, sender, receiver, subject, body):
        self.sender = sender      # a User object
        self.receiver = receiver  # a User object
        self.subject = subject
        self.body = body

class Inbox:
    def __init__(self):
        self.emails = []

    def receive_email(self, email):
        self.emails.append(email)

class User:
    def __init__(self, name):
        self.name = name
        self.inbox = Inbox()  # each user has its own Inbox object

    def send_email(self, receiver, subject, body):
        email = Email(sender=self, receiver=receiver, subject=subject, body=body)
        receiver.inbox.receive_email(email)

tory = User('Tory')
ramy = User('Ramy')

tory.send_email(ramy, 'Hello', 'Hi Ramy, just saying hello!')

print(len(ramy.inbox.emails))              # 1
print(ramy.inbox.emails[0].sender.name)    # Tory
```

In this example, `send_email()` passes the current user (`self`) and the `receiver` object to `Email`, then delivers the new email through the receiver's `inbox` attribute.

## Dunder (Magic) Methods

- **Definition**: Special methods that start and end with a double underscore (e.g., `__init__`, `__len__`, `__str__`, `__eq__`). Python uses them internally for built-in operations.

- **Why Custom Classes Need Special Methods**: Built-in types like strings and numbers already know how to report their length, convert to text, and compare for equality. A class you create doesn't know how to do these things until you define the matching special methods. Here's what happens with a plain `Book` class:

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

book1 = Book('Built Wealth Like a Boss', 420)
book2 = Book('Be Your Own Start', 420)

try:
    print(len(book1))
except TypeError:
    print("TypeError: object of type 'Book' has no len()")
print(str(book1))      # <__main__.Book object at 0x102ed2900>
print(book1 == book2)  # False
```

- `len(book1)` raises a `TypeError` because the class doesn't define `__len__()`, so Python doesn't know how to get the object's length.
- `str(book1)` returns the default representation, which shows the class name and memory address instead of a readable summary of the book.
- `book1 == book2` is `False` because, by default, `==` only checks whether both variables refer to the same object in memory, not whether they have the same content. Even though both books have 420 pages, they are distinct instances.

- **Customizing Behavior with Special Methods**: Defining `__len__()`, `__str__()`, and `__eq__()` changes how these operations work for `Book` objects. `len()` now returns the number of pages, `str()` returns a readable summary, and `==` compares books by their number of pages:

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __len__(self):
        return self.pages

    def __str__(self):
        return f"'{self.title}' has {self.pages} pages"

    def __eq__(self, other):
        return self.pages == other.pages

book1 = Book('Built Wealth Like a Boss', 420)
book2 = Book('Be Your Own Start', 420)
print(len(book1))        # 420
print(str(book1))        # 'Built Wealth Like a Boss' has 420 pages
print(book1 == book2)    # True
```

- **Calling dunder methods indirectly**: You don't need to call dunder methods directly. Instead, Python automatically calls them when certain actions happen. These operations include:

  - **arithmetic operations like addition, subtraction, multiplication, division, and others**. `__add__()` is called for addition, `__sub__()` for subtraction, `__mul__()` for multiplication, and `__truediv__()` for division.
        
  - **string operations like concatenation, repetition, formatting, and conversion to text**. `__add__()` is called for concatenation, `__mul__()` for repetition, `__format__()` for formatting, `__str__()` and `__repr__()` for text conversion, and so on.
        
  - **comparison operations like equality, less-than, greater-than, and others**. `__eq__()` is called for equality checks, `__lt__()` for less-than, `__gt__()` for greater-than, and so on.
        
  - **iteration operations like making an object iterable and advancing through items**. `__iter__()` is called to return an iterator and `__next__()` to fetch the next item.

## Real World Example: Shopping Cart

- **Cart Class with Dunder Methods**: Allows adding, removing, iterating, and checking contents with built-in behavior.

```python
class Cart:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    def remove(self, item):
        if item in self.items:
            self.items.remove(item)
        else:
            print(f'{item} is not in cart')

    def list_items(self):
        return self.items

    def __len__(self):
        return len(self.items)

    def __getitem__(self, index):
        return self.items[index]

    def __contains__(self, item):
        return item in self.items

    def __iter__(self):
        return iter(self.items)

cart = Cart()
cart.add('Laptop')
print(len(cart))        # 1
print('Laptop' in cart) # True
```

## Working with Timestamps

- **Getting the Current Date and Time**: After importing the `datetime` module, `datetime.datetime.now()` returns a `datetime` object holding the current date and time.

- **Storing a Timestamp on an Instance**: You can assign `datetime.datetime.now()` to an attribute in `__init__()` to automatically record when each object was created.

- **Formatting with `strftime()`**: The `strftime()` method formats a `datetime` object as a string using format codes. Any other characters in the format string, like `-`, `:`, or spaces, are included literally as separators. Common format codes include:

  - `%Y`: four-digit year (e.g., `2024`)
  - `%m`: two-digit month (e.g., `03`)
  - `%d`: two-digit day of the month (e.g., `15`)
  - `%H`: hour in 24-hour format (e.g., `14`)
  - `%M`: minutes (e.g., `05`)
  - `%S`: seconds (e.g., `09`)

```python
import datetime

class Email:
    def __init__(self, subject):
        self.subject = subject
        self.timestamp = datetime.datetime.now()

email = Email('Hello')

print(email.timestamp.strftime('%Y-%m-%d'))        # 2024-03-15
print(email.timestamp.strftime('%H:%M:%S'))        # 14:05:09
print(email.timestamp.strftime('%Y-%m-%d %H:%M'))  # 2024-03-15 14:05
```
